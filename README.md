# Admin Panel CV Mitra Koperasi Nusantara

Aplikasi dashboard admin untuk mengelola data konsultan koperasi berbasis Next.js 14 (App Router).

## Fitur

- **Timeline Kegiatan 12 Bulan** – kelola kegiatan per bulan & kategori
- **Tracker Progress Bulanan** – tracking target klien & omset bulanan
- **Analisis SWOT** – matriks SWOT & strategi (SO, WO, ST, WT)
- **Rencana Anggaran Usaha** – investasi awal & proyeksi pendapatan 3 tahun
- **Dashboard** – ringkasan jumlah data dari setiap modul

## Teknologi

- **Frontend**: Next.js 14 (App Router), React, CSS-in-JS (inline styles)
- **Backend**: Next.js API Routes
- **Database**: MySQL (via `mysql2/promise`)
- **Autentikasi**: NextAuth.js (opsional, sesuaikan)
